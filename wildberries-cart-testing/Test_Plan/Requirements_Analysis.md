# Анализ функционала корзины Wildberries(ручное тестирование)

## Основные функции:
- Добавление товара в корзину
- Управление количеством товаров
- Применение промокодов
- Расчет итоговой суммы
- Сохранение корзины между сессиями
- Оформление заказа из корзины

## Обнаруженные элементы:
- Кнопка "В корзину" на карточке товара
- Иконка корзины в хедере с счетчиком
- Страница корзины с списком товаров
- Кнопки "+"/"-" для изменения количества
- Кнопка "Удалить" 
- Поле для промокода
- Блок с итоговой суммой
