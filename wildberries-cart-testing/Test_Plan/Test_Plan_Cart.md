# Тест-план: Корзина Wildberries

## Цели ручного тестирования

- Проверить корректность работы функционала корзины
- Выявить критические ошибки в основных сценариях
- Оценить удобство пользовательского интерфейса

## Объем тестирования

**Включает:**

- ✓ Базовая функциональность корзины
- ✓ Управление количеством товаров
- ✓ Расчеты и цены

**Не включает:**

- ✗ Платежная система (только до момента оплаты)
- ✗ Система доставки (только выбор способа)

## Подход к тестированию

- **Ручное функциональное тестирование** - проверка основных сценариев
- **Кросс-браузерное тестирование** - Chrome, Firefox, мобильные браузеры

## Критерии качества

- Корзина сохраняется при перезагрузке страницы
- Счетчик в хедере отображает актуальное количество
- Итоговая сумма рассчитывается корректно

## Критерии начала тестирования

- Доступность тестового окружения (сайт wildberries.ru)
- Определены тестовые данные и сценарии

## Критерии окончания тестирования

- Пройдены все запланированные тест-кейсы
- Подготовлен итоговый отчет о тестировании

## Расписание(предполагаемое)

- **Подготовка:** 1 день (создание тестовой документации)
- **Основное тестирование:** 3 дня (прогон всех тест-кейсов)

## Риски(предполагаемые)

- **Высокий:** Изменение функционала на сайте в процессе тестирования
- **Средний:** Недоступность сайта или отдельных функций
- **Низкий:** Нехватка времени на полное тестирование всех сценариев
- **Низкий:** Отсутствие тестовых данных (определенных товаров)

## Окружение

- **Браузеры:** Chrome 141, Firefox 144,
- **Устройства:** Desktop (1920x1080), Mobile (375x667), Tablet (768x1024)
- **Сеть:** Стабильное интернет-соединение
