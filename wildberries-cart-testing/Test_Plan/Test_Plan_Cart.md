# Тест-план: Корзина Wildberries

## Цели тестирования

- Проверить корректность работы базового функционала корзины
- Выявить критические и блокирующие ошибки в основных сценариях
- Оценить удобство пользовательского интерфейса и UX
- Проверить интеграцию корзины со смежными системами

## Объем тестирования

**Включает:**

- ✓ Базовая функциональность корзины
- ✓ Управление количеством товаров
- ✓ Расчеты и цены
- ✓ Интеграционные сценарии
- ✓ Кросс-браузерная совместимость
- ✓ Работа на мобильных устройствах

**Не включает:**

- ✗ Платежная система (только до момента оплаты)
- ✗ Система доставки (только выбор способа)
- ✗ Нагрузочное тестирование
- ✗ Тестирование безопасности
- ✗ Юзабилити-тестирование с реальными пользователями

## Подход к тестированию

- **Ручное функциональное тестирование** - проверка основных сценариев
- **Регрессионное тестирование** - проверка критического функционала после изменений
- **Кросс-браузерное тестирование** - Chrome, Firefox, мобильные браузеры
- **Тестирование интеграций** - корзина для авторизованных/неавторизованных пользователей, синхронизация данных

## Критерии качества

- Корзина сохраняется при перезагрузке страницы
- Счетчик в хедере отображает актуальное количество
- Итоговая сумма рассчитывается корректно
- Все основные операции выполняются без ошибок
- Интерфейс корректно отображается в поддерживаемых браузерах
- Время отклика операций не превышает 3 секунд

## Критерии начала тестирования

- Доступность тестового окружения (сайт wildberries.ru)
- Наличие минимальной документации (анализ требований завершен)
- Определены тестовые данные и сценарии
- Готовность чек-листов и тест-кейсов

## Критерии окончания тестирования

- Пройдено 100% запланированных тест-кейсов
- Все критические и блокирующие баги исправлены и перепроверены
- Пройдено регрессионное тестирование по критическим сценариям
- Подготовлен итоговый отчет о тестировании

## Расписание

- **Подготовка:** 1 день (создание тестовой документации)
- **Основное тестирование:** 3 дня (прогон всех тест-кейсов)
- **Регрессия:** 1 день (проверка исправленных багов)
- **Отчетность:** 0.5 дня (подготовка финального отчета)

## Риски

- **Высокий:** Изменение функционала на сайте в процессе тестирования
- **Средний:** Недоступность сайта или отдельных функций
- **Низкий:** Нехватка времени на полное тестирование всех сценариев
- **Низкий:** Отсутствие тестовых данных (определенных товаров)

## Окружение

- **Браузеры:** Chrome 141, Firefox 144,
- **Устройства:** Desktop (1920x1080), Mobile (375x667), Tablet (768x1024)
- **Сеть:** Стабильное интернет-соединение
- **Аккаунты:** Тестовые учетные записи Wildberries
