# Баг: Ошибка при проверке доступности изображений

## Описание
При проверке семантической разметки страницы iPhone возникает ошибка "object is not iterable" при анализе изображений.

## Серьезность: Medium
## Приоритет: Medium

## Шаги воспроизведения
1. Запустить тест доступности: `npm run test:accessibility`
2. Дождаться выполнения шага "Проверка семантической разметки"
3. Наблюдать ошибку в консоли

## Ожидаемый результат
Тест должен корректно подсчитать количество изображений с alt-текстом

## Фактический результат
Тест падает с ошибкой: `TypeError: object is not iterable`

## Окружение
- Браузер: Chrome 142.0.7444.60
- ОС: Windows
- Тест: accessibility.test.js

## Причина ошибки
Код неправильно обрабатывает коллекцию элементов изображений. Метод `map` не работает с WebElement коллекциями.
